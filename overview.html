How to use ResearchGraph

Tree Structure

  • Nodes organize your work into a tree hierarchy (phases, groups, sub-groups — unlimited depth)
  • Elements are the actual items (experiments, constructs, tasks) that live inside nodes
  • Click any node or element to see its details in the right panel

Drag & Drop

  • Drag elements between nodes to reorganize them
  • Drag nodes to reorder or move them into different parent nodes

Adding Items

  • + Add Node (top left) creates a new top-level node
  • +Sub button on a node creates a child node
  • + button on a node or the ghost card opens the Add Element dialog

Detail Panel (right side)

  • Edit titles and descriptions by clicking on them directly
  • Use @mentions in descriptions to link to other elements or nodes
  • Add custom sections for notes, protocols, or troubleshooting
  • Add link sections to cross-reference related elements
  • Activity log tracks changes automatically; add manual notes too

Tags & Statuses

  • Create custom tags (right sidebar) — the first tag sets the card color
  • Create custom statuses with icons and colors
  • Filter by status using the pills in the header

Views

  • Tree — hierarchical view of all nodes and elements
  • Board — elements grouped by status (Kanban-style)
  • Lab — to-do lists and a lab journal

Projects

  • Use project tabs in the header to switch between projects
  • Each project has its own nodes, elements, tags, and statuses
  • Click ⚙ to manage projects (rename, recolor, delete)

Sync & Data

  • GitHub Sync — connect a GitHub token to sync data across devices via Gists
  • ⬆ Export / ⬇ Import your data as JSON
  • All data is saved in your browser's localStorage — no account needed

Shortcuts

  • Ctrl+F — search nodes and elements
  • Ctrl+Z — undo last action
  • Ctrl+Click — multi-select elements for bulk status change or delete

Danger Zone

Deletes all data in this project and reloads.
